# مزاج كافيه — HTML / CSS / JavaScript

افتح `index.html` مباشرة في المتصفح.

الرمز الافتراضي: `2580`

المكان السري (زر ◈) يحتوي على:
- إدارة المنتجات والأسعار
- إضافة/تعديل/حذف المنتجات
- إدارة التصنيفات
- تغيير اسم الكافيه والعنوان والوصف والعملة
- تغيير الرمز السري

كل البيانات محفوظة في localStorage.

تنبيه أمني: هذا مشروع Front-end فقط. الرمز السري في JavaScript قابل للاستخراج من ملفات الموقع. للإنتاج الحقيقي استخدم Backend وقاعدة بيانات ومصادقة بخادم.
