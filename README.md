# مشروع منيو كافيه

## التشغيل
1. ثبّت Node.js 18.17+.
2. افتح مجلد المشروع.
3. شغّل:
   `npm install`
4. ثم:
   `npm run dev`
5. افتح `http://localhost:3000`.

## لوحة المالك
اضغط رمز ⚙ أعلى الصفحة.
رمز التجربة الحالي: `2580`

### تنبيه أمني مهم
هذا الإصدار يعمل بالكامل من الواجهة ويستخدم localStorage، لذلك هو **نسخة تجريبية/واجهة جاهزة للتطوير** وليس نظام إدارة آمن للإنتاج. لا تضع بيانات سرية حقيقية فيه.

للنشر الحقيقي، يجب نقل:
- المصادقة والتحقق من الرمز إلى backend.
- تخزين المنتجات في قاعدة بيانات.
- تخزين كلمة المرور/الرمز بشكل hash وليس كنص داخل JavaScript.
- إضافة جلسة آمنة (HTTP-only cookie) وحماية CSRF/rate limiting.
